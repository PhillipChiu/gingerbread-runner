# 雲尾衝刺日記

一款以 React、TypeScript、Canvas 與 Vite 製作的繁體中文單頁跑酷遊戲。小跑者會自動向前奔跑；玩家在十段逐步加速、障礙變密的原創步道上跳躍、滑行並收集能量果實。遊戲動作只有跳躍與滑行。

## 開始遊玩

需求：Node.js 20 以上、npm。

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址即可遊玩。遊戲不需要 API、資料庫或後端服務。

### 操作方式

| 動作 | 鍵盤 | 觸控 |
| --- | --- | --- |
| 跳躍 | `Space`、`↑` 或 `W` | 點選「跳躍」 |
| 滑行 | `↓` 或 `S` | 點選「滑行」 |
| 暫停／繼續 | `P` 或 `Esc` | 遊戲畫面的「暫停」按鈕 |

桌機可用滑鼠點選 Canvas 下方的「跳躍」與「滑行」大按鈕，也可使用表列鍵盤操作。手機直式畫面把兩個動作放在跑道下方的安全區操作列；手機橫式畫面則將跳躍固定在跑道左側、滑行固定在最右側，暫停留在上方列。Canvas 在各種方向都維持 16:7 比例；橫式畫面請以安全區內左右兩側的大按鈕操作。

角色會自動前進。跳過障礙、滑過低矮障礙，並收集能量果實。單一「體力」資源決定本次奔跑是否結束：體力會隨時間消耗，碰撞會扣減體力，能量果實則可補充體力；歸零時本次奔跑結束。抵達關卡路程目標即可通關並解鎖下一關，也可以重玩已解鎖的關卡。

不同高度的果實需要配合跳躍或滑行收集。可在開始畫面選擇開啟螢幕閱讀器跑道提示；輔助技術會播報關卡開始、前方障礙類型與結算結果，不會逐幀播報 HUD。

### 本 Prototype 的自訂平衡

下列數值是本遊戲自行設定的平衡，**不是官方數值或已確認的官方規則**：初始體力 100 點、每秒消耗 1.2 點、每次碰撞扣 34 點、每顆能量果實補充 18 點。各關以距離作為本遊戲自訂通關任務，收集數作為本遊戲自訂紀錄；關卡距離、速度、障礙樣式與分數公式也都是本遊戲自訂設計。

## 專案指令

```bash
npm test        # 執行關卡資料、遊戲狀態與進度儲存測試
npm run build   # TypeScript 檢查並產生 production build
npm run preview # 本機預覽 dist
```

分數、已通關關卡、解鎖進度、最佳分數與收集總數以 `localStorage` 儲存在目前瀏覽器，不會傳送到伺服器。

## GitHub Pages 部署

`.github/workflows/deploy-pages.yml` 會在 `main` 分支更新或手動觸發時執行測試、build，並部署到 GitHub Pages。請在 GitHub repository 的 **Settings → Pages → Build and deployment** 選擇 **GitHub Actions**。

部署建置會將 Vite 的 asset base 設為 `/gingerbread-runner/`，適用於 `gingerbread-runner` repository；一般本機開發與預覽仍使用 `/`。角色圖由 Vite 直接從 repo 根目錄匯入、打包，原始 `main_character.png` 會保留不變。

## 素材與實作

- 遊戲主角使用 repo 提供的 `main_character.png`。程式將角色圖格裁切、移除圖片上與角色不相連的淺色格紋背景，並在 Canvas 中循環播放角色姿勢。
- 選單角色預覽會配合系統的「減少動態效果」偏好顯示靜態姿勢；遊戲本身仍可正常操作。
- 場景、障礙、果實與介面以原創 Canvas 繪圖及 CSS 製作；沒有使用官方品牌識別、角色素材或音效。
- 十關資料集中在 `src/game/levels.ts`；自動移動、跳躍、滑行、碰撞、體力與計分邏輯位於 `src/game/engine.ts`。
